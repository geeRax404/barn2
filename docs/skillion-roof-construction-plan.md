# Skillion and Double Skillion Roof Construction Plan

## 1. SPECIFIC MEASUREMENTS

### 1.1 Skillion Roof Structure
**Overall Dimensions:**
- Span: 15.24m (50 feet)
- Length: 24.38m (80 feet)
- Front wall height: 4.88m (16 feet)
- Back wall height: 3.66m (12 feet)
- Height difference: 1.22m (4 feet)
- Roof pitch: 2.5:12 (11.8°)

**Wall Elevations:**
- Ground level to front wall base: +10mm offset
- Ground level to back wall base: +10mm offset
- Front wall top: 4.89m above ground
- Back wall top: 3.67m above ground

### 1.2 Double Skillion (Butterfly) Roof Structure
**Overall Dimensions:**
- Span: 15.24m (50 feet)
- Length: 24.38m (80 feet)
- Perimeter wall height: 4.88m (16 feet)
- Valley height: 3.66m (12 feet)
- Height difference: 1.22m (4 feet)
- Roof pitch: 3:12 (14.0°) each slope

**Wall Elevations:**
- Ground level to perimeter walls: +10mm offset
- Perimeter wall tops: 4.89m above ground
- Valley beam height: 3.67m above ground

## 2. CONSTRUCTION SPECIFICATIONS

### 2.1 Roof Frame Components

**Primary Structural Members:**
- Ridge beam (Skillion): 300mm x 75mm LVL (Laminated Veneer Lumber)
- Valley beam (Double Skillion): 400mm x 90mm LVL
- Rafters: 240mm x 45mm F7 Pine @ 600mm centres
- Wall plates: 90mm x 45mm F7 Pine
- Ceiling joists: 190mm x 45mm F5 Pine @ 450mm centres

**Connection Hardware:**
- Galvanised joist hangers: 240mm x 45mm
- Galvanised angle brackets: 90mm x 90mm x 65mm
- Coach screws: M12 x 150mm for beam connections
- Galvanised nails: 75mm x 3.15mm for general framing
- Cyclone ties: AS1684 compliant for rafter-to-plate connections

### 2.2 Support Beam Requirements

**Skillion Roof:**
- Main support beam: 450mm x 90mm LVL spanning 15.24m
- Intermediate posts: 150mm x 150mm F17 Hardwood @ 3.05m centres
- Footings: 600mm x 600mm x 300mm concrete pads
- Post-to-beam connections: Galvanised post caps

**Double Skillion Roof:**
- Valley beam: 600mm x 90mm LVL spanning 24.38m
- Support posts: 200mm x 200mm F17 Hardwood @ 4.88m centres
- Footings: 800mm x 800mm x 400mm concrete pads
- Valley beam supports: Steel fabricated brackets

### 2.3 Drainage Considerations

**Skillion Roof Drainage:**
- Primary drainage: 150mm PVC gutters along low edge
- Downpipes: 100mm PVC @ 10m centres maximum
- Roof slope: Minimum 1:40 (1.4°) for sheet metal
- Overflow provision: 25mm above gutter level

**Double Skillion Drainage:**
- Valley gutter: 200mm wide x 100mm deep custom fabricated
- Valley drainage: 150mm PVC pipe with 1:100 fall minimum
- Perimeter gutters: 125mm PVC standard profile
- Sump pit: 600mm x 600mm x 600mm at valley low point

### 2.4 Flashing Details

**Critical Flashing Points:**
- Ridge flashing: 300mm wide Colorbond steel, 0.48mm BMT
- Valley flashing: 400mm wide with 150mm upstands each side
- Wall-to-roof junction: 200mm wide step flashing
- Penetration flashing: Lead boots for all roof penetrations

**Installation Specifications:**
- Overlap: Minimum 150mm for all horizontal joints
- Fasteners: Stainless steel screws with EPDM washers
- Sealant: Neutral cure silicone for all exposed joints
- Membrane: Self-adhering butyl tape under all flashings

### 2.5 Roofing Material Options

**Option 1: Colorbond Steel (Recommended)**
- Profile: Trimdek or Custom Orb
- Thickness: 0.48mm BMT (Base Metal Thickness)
- Fasteners: Class 4 stainless steel screws
- Insulation: R2.5 bulk insulation + reflective foil

**Option 2: Standing Seam Metal**
- Material: Aluminium or Zincalume
- Thickness: 0.7mm for structural spans
- Clips: Concealed fixed clips @ 600mm centres
- Thermal movement: 20mm expansion joints @ 30m

**Option 3: Membrane Roofing**
- System: EPDM or TPO single membrane
- Thickness: 1.5mm minimum
- Substrate: 18mm structural plywood
- Insulation: Rigid foam boards, R3.5 minimum

## 3. STEP-BY-STEP INSTALLATION SEQUENCE

### 3.1 Foundation Preparation

**Step 1: Site Survey and Marking**
- Establish datum level with +10mm offset for wall bases
- Mark all footing locations with spray paint
- Check for underground services (Dial Before You Dig)
- Set up temporary benchmarks for height reference

**Step 2: Excavation**
- Excavate footings to 300mm below finished floor level
- Compact base with plate compactor (95% standard compaction)
- Install 75mm crushed rock base, compacted in 25mm lifts
- Place reinforcement mesh (SL72 minimum)

**Step 3: Concrete Footings**
- Pour 25MPa concrete with 80mm slump
- Install galvanised anchor bolts (M16 x 400mm)
- Level and cure for minimum 7 days
- Apply damp-proof membrane to top surface

### 3.2 Wall Attachment Methods

**Step 4: Wall Plate Installation**
- Position wall plates with +10mm ground offset
- Check level using laser level or water level
- Secure with galvanised washers and nuts
- Apply sill sealer tape under all plates

**Step 5: Wall Frame Erection**
- Assemble wall frames on ground where possible
- Use temporary bracing during erection
- Check plumb and square before permanent fixing
- Install permanent diagonal bracing as per AS1684

### 3.3 Beam Placement

**Step 6: Primary Beam Installation (Skillion)**
- Crane lift main support beam into position
- Check beam level and alignment
- Secure with galvanised brackets and coach screws
- Install temporary props until roof load applied

**Step 7: Valley Beam Installation (Double Skillion)**
- Position valley beam at calculated height (3.67m)
- Ensure proper fall for drainage (1:100 minimum)
- Connect to support posts with fabricated brackets
- Check alignment with string line

### 3.4 Rafter Installation

**Step 8: Rafter Layout and Cutting**
- Mark rafter positions @ 600mm centres
- Cut rafters to calculated lengths with appropriate angles
- Skillion: Single angle cut at ridge end
- Double Skillion: Compound angles for valley connection

**Step 9: Rafter Installation**
- Install rafters starting from one end
- Use joist hangers for beam connections
- Secure to wall plates with cyclone ties
- Check rafter spacing and alignment continuously

**Step 10: Ceiling Joist Installation**
- Install ceiling joists @ 450mm centres
- Connect to wall plates and rafters
- Provide adequate ventilation gaps
- Install temporary ceiling to support insulation

### 3.5 Roofing Material Application

**Step 11: Sarking and Insulation**
- Install reflective foil sarking over rafters
- Overlap joints by 150mm minimum
- Tape all joints with foil tape
- Install bulk insulation between ceiling joists

**Step 12: Roof Sheeting Installation**
- Start installation from low edge (drainage end)
- Overlap sheets according to manufacturer's specifications
- Use appropriate fasteners for roof pitch and exposure
- Install ridge capping and flashings as work progresses

**Step 13: Gutter and Downpipe Installation**
- Install fascia boards and gutter brackets
- Position gutters with appropriate fall (1:500 minimum)
- Connect downpipes with adequate fixing
- Test drainage system thoroughly

**Step 14: Final Inspections**
- Check all structural connections
- Verify weatherproofing integrity
- Test drainage under simulated rainfall
- Obtain building compliance certificate

## 4. SAFETY CONSIDERATIONS

**Fall Protection:**
- Install safety mesh or scaffolding for roof work
- Use appropriate harnesses and anchor points
- Maintain 3-point contact when on roof
- Weather restrictions: No work in winds >40km/h

**Structural Safety:**
- Temporary bracing required during construction
- Load calculations verified by structural engineer
- Progressive loading during material installation
- Regular inspection of temporary supports

## 5. QUALITY CONTROL CHECKPOINTS

**Critical Inspection Points:**
1. Foundation level and alignment
2. Wall plate level and fixing
3. Beam installation and support
4. Rafter spacing and connection
5. Flashing installation and sealing
6. Final drainage testing

**Documentation Required:**
- Structural engineer's certification
- Building surveyor inspections
- Material compliance certificates
- Warranty documentation for all components

## 6. MAINTENANCE SCHEDULE

**Annual Inspections:**
- Gutter and downpipe cleaning
- Flashing and sealant inspection
- Fastener tightness check
- Drainage system testing

**5-Year Maintenance:**
- Roof coating renewal (if applicable)
- Structural connection inspection
- Insulation condition assessment
- Complete weatherproofing review

This construction plan ensures proper ground alignment with the +10mm offset while maintaining structural integrity and weather resistance for both Skillion and Double Skillion roof systems.
